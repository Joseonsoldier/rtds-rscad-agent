## Retained behavior and integration decisions

- JSON Schema is authoritative for structured batch and test-spec contracts; MCP schema exposure and direct validation share it. Existing Runtime semantic validation remains in force. The public `offline_frequency_scan` and backend `offline_analytical_frequency_scan` mode spellings are accepted aliases without normalizing or rewriting saved plans/hashes.
- Parameter generations preserve historical DB/audit evidence. Only an explicit validated migration converts legacy data; no previous workflow/grant hash is refreshed. New compile result references include SHA-256; old unhashed diagnostic artifacts are explicitly unsupported.
- Project queries deliberately rehash/reparse rather than introduce an inadequately keyed persistent cache. Shared normalized static topology ignores incidental net ordering/IDs but includes wire geometry; it is not electrical equivalence. Electrical phase ports remain undirected; no multi-stage causal trace is claimed.
- Independent review reproduced two patch safety defects: a transient mutable-source edit could inject an unrequested parameter, and import-time definition paths could miss a dependency after configuration changed. Patches now derive output from the verified snapshot, capture current settings for the transaction, and reject mid-transaction changes. Both original reproductions were independently rerun and blocked; regression tests preserve the cases.
- Cleanup reporting separates stop/restoration from close/disconnect. Successful close/disconnect with failed or unknown stop cannot become overall successful Runtime cleanup. Failed initialization records not-started/unknown states honestly and retains consumed attempts.
- Assessments record caller-declared provenance and run/attempt identities but do not authenticate them as live simulator execution. Numerical threshold success does not change `engineering_verdict: not_evaluated`. No implicit units conversion, interpolation, invented criteria or causal attribution.
